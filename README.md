# 📝 To-Do List App (Tkinter Edition)

A simple desktop To-Do list app built using Python and Tkinter —  
add tasks, delete tasks, and keep your chaos slightly more organized.

---

## 🧠 What it does

- ➕ **Add Tasks**: Type and hit enter. It’s in.
- ❌ **Delete Tasks**: Select a task, hit delete. Gone.
- 💾 **Auto Save**: All tasks are stored in `tasklist.txt` and reloaded on startup.
- 🖼️ **Custom UI**: Styled with custom icons and background images (pngs included).

---

## 📁 Files Required

To run the app as intended, make sure these image files are in the same directory:
- `task.png`  
- `topbar.png`  
- `dock.png`  
- `delete.png`

---

## 🛠 Requirements

- Python 3.x  
- Tkinter (usually bundled with Python)
